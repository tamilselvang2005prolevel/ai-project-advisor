# AI Project Advisor (Free, Browser-Only)

- Runs completely in the browser with WebLLM (no API keys).
- Deploy as static site (e.g., Vercel).
- Produces structured JSON with components, tools, steps, cost, timeline, and rating.

## Dev
Open `index.html` in a modern Chrome/Edge. If WebGPU is unavailable, try enabling chrome://flags/#enable-unsafe-webgpu
